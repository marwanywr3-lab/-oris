# Oris — AI Smart Daily Scheduler (PWA)

A zero-backend, bilingual (Arabic RTL / English LTR) smart daily scheduler powered by Google AI Studio (Gemini API) and browser Web Speech API, ready for static hosting on **GitHub Pages**.

## Features
- **Claude-Inspired Warm Minimalist Palette**: Warm Alabaster (`#FAF9F6`), Deep Charcoal (`#141413`), and Terracotta Coral (`#D97757`).
- **Smart Onboarding**: Sets up your API key, locked sleep hours, core work/study schedule, and hobby windows.
- **Oris AI Assistant**: Add, edit, delete tasks, or navigate between views/days using natural text or voice commands.
- **Hands-Free Wake Word**: Say `"Hi Oris"` or `"مرحبا Oris"` while the app is open to trigger voice commands without wasting API tokens during silence.
- **100% Client-Side & PWA**: All data stays in `localStorage` with JSON export/import and offline PWA caching.

## Deploy on GitHub Pages
1. Upload all files in this folder to the root of a GitHub repository.
2. Go to **Settings → Pages**, select the `main` branch and `/ (root)` folder, and click **Save**.
3. Open your GitHub Pages URL, enter your Google AI Studio API key during onboarding, and install it on your phone via **Add to Home Screen**.
